# 🤖 AI-FiyatEksperi
### Bölgesel Veri Analizi Tabanlı Taşınmaz ve Araç Değerleme Asistanı

Bu uygulama, Karabük Üniversitesi Yapay Zeka programı kapsamında geliştirilmiş bir fiyat tahmin sistemidir.

## 🚀 Özellikler
* **🚗 Araba Değerleme:** Yaş, KM, hasar kaydı ve boya durumuna göre analiz.
* **🏠 Ev Değerleme:** Bölge katsayıları, metrekare, kat ve cephe durumuna göre tahmin.
* **🌍 Bulut Tabanlı:** Streamlit Cloud üzerinden her yerden erişilebilir.

## 🛠️ Teknik Altyapı
* **Dil:** Python
* **Arayüz:** Streamlit
* **Veri:** Bölgesel piyasa katsayıları
